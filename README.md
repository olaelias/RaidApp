# Raid Journal

A simple Swedish-language console application for tracking and documenting raids.

## Features

- Start a new raid with a goal and purpose
- Keep one active raid at a time
- End raids with a required comment
- Automatically save completed raids
- Browse raid history by year and month
- Edit comments in existing log entries

## Storage

Data is stored locally in JSON files:

- active_raid.json
- raid_log.json

## Language

The application interface is entirely in Swedish.

## Technology

- C#
- .NET
- Console Application
